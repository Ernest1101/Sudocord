# Getting Started

## Where to Start?

Welcome to the SudoCord documentation! This guide will help you get started with installing and using SudoCord.

## What is SudoCord?

**SudoCord** is a Vencord fork that is actively maintained by mrernestyt and comes with a bunch of custom-built plugins on top of everything Vencord offers. You can find the full plugin list [on the website](https://sudocord.h4ck.me/plugins) or in the [GitHub repository](https://github.com/Ernest1101/Sudocord) under `src/userplugins`.

Highlights among the custom plugins:

- **DecibelLimiter** — real-time dB meter for voice + automatic volume lowering of loud users
- **StreamQuality** — custom FPS / resolution / bitrate for your streams
- **SpoofPlatform** — pretend to play from any platform
- **UpdateButton** — one-click SudoCord updates right from the header bar

**Sudotl** is the installer that adds SudoCord to your existing Discord client. Learn more in the [Sudotl GitHub repository](https://github.com/Ernest1101/Sudotl).

SudoCord updates itself automatically from devbuilds — and there is an update button right in the header bar, so you are always on the latest version.

SudoCord supports Windows, Linux, and macOS.
