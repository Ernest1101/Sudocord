# FakeMessages

Плагин для Vencord (userplugin), который позволяет создавать **визуальные** сообщения
от имени собеседника в личных сообщениях.

## Как работает

1. Откройте ЛС с человеком — в панели ввода рядом с кнопками появится иконка
   «человек с плюсом».
2. Нажмите на неё — откроется окно: выберите, от кого пишем (по умолчанию собеседник),
   введите текст и нажмите «Создать».
3. Сообщение появится в чате как настоящее — с аватаркой, именем и временем.

## Важно

- Это **чисто визуал**: сообщение существует только в вашем клиенте и никуда не
  отправляется — собеседник его не увидит.
- Сообщения **не сбрасываются** при переключении между чатами — вернётесь в ЛС,
  и всё на месте.
- С включённой настройкой «Сохранять после перезапуска» фейки переживают и
  перезапуск Discord.

## Удаление

Правый клик по фейковому сообщению → **«Удалить фейковое сообщение»**,
либо «Удалить все фейковые (N)» — для очистки всего чата.
