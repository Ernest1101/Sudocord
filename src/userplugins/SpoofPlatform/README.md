# SpoofPlatform

Плагин для Vencord (userplugin), который подменяет устройство, с которого вы
«сидите» в Discord — его увидят все остальные пользователи.

## Что можно выбрать

| Устройство | Что видят другие |
|---|---|
| ПК — Windows / macOS / Linux | Иконка компьютера |
| Телефон — iPhone (iOS) | Иконка телефона + пометка «отправлено с iPhone» у сообщений |
| Телефон — Android | Иконка телефона |
| Браузер (Chrome) | Иконка браузера |
| Консоль (Xbox/PlayStation) | Иконка геймпада, как у игроков с консоли |
| VR (Quest) — экспериментально | Иконка VR-шлема (может показаться иконка браузера) |

## Как использовать

1. Включите плагин в настройках Vencord.
2. Выберите устройство в настройках плагина.
3. **Перезапустите клиент (Ctrl+R)** — платформа отправляется на сервер только
   при подключении (в пакете IDENTIFY), поэтому смена применяется после
   реконнекта.

## Как это работает

Плагин патчит код gateway-менеджера (`_doIdentify`), который собирает пакет
IDENTIFY при подключении, и подмешивает свои поля в `properties` (browser, os,
при необходимости User-Agent). Патч применяется до выполнения кода — спуф
гарантированно попадает в самое первое подключение после перезагрузки.

VR-вариант экспериментальный: Discord распознаёт реальный Quest-клиент по
User-Agent браузера, поэтому плагин подменяет и его — но сервер может всё равно
классифицировать сессию как веб.
