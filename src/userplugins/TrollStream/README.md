# TrollStream

Плагин-тролль для Vencord (userplugin): по-настоящему и бесконечно быстро
включает и выключает демонстрацию экрана в голосовом канале. Управляется
кнопкой в чате.

## Как использовать

1. **Один раз** запусти демонстрацию экрана вручную и останови её — Discord
   запомнит источник и качество (нужно, чтобы тролль мог запускать её сам).
2. Зайди в голосовой канал.
3. Нажми кнопку с молнией 🌩️ в панели ввода — демонстрация начнёт включаться и
   выключаться бесконечно: у всех в канале плитка стрима и уведомления будут
   появляться и пропадать. Кнопка при этом горит красным.
4. Повторное нажатие — остановить.

## Детали

- Используются настоящие внутренние функции Discord запуска/остановки стрима
  (те же, что вызываются кнопкой «Демонстрация»).
- При выходе из голосового канала троллинг останавливается автоматически.
- Настройка «Пауза между вкл/выкл» — по умолчанию 1500 мс: реальному стриму
  нужно время на подключение, слишком маленькие значения сделают мигание
  незаметным.
